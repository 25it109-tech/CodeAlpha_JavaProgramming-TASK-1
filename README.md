# Task 1: Student Grade Tracker

## 📋 Project Description
A Java console-based application to manage student grades. This project allows users to input student details and grades, calculate averages, and generate a summary report.

## ✨ Features
- Add multiple students with multiple subjects
- Calculate individual student average, highest, and lowest scores
- Display class average, top and bottom performer
- Uses ArrayList and arrays for data management
- Clean formatted console output

## 🛠 Technologies Used
- Java (JDK 21)
- ArrayList
- Scanner for user input

## 🚀 How to Run
1. Open the project in VS Code
2. Compile: `javac StudentGradeTracker.java`
3. Run: `java StudentGradeTracker`
